# Priest Ledger App
A cloud-connected, multilingual (English/Tamil) financial ledger designed for managing temple duties, homams, and personal accounting.

## Features
* **Google Authentication:** Secure, scoped login.
* **Firestore Sync:** Real-time data storage with strict user isolation.
* **Custom Scoped Categories:** Create specific categories per ledger tab.
* **Annual Master Archive:** Export the entire year's categorized data into a professional PDF.
